# 반응형 검증 기록 (spec §17.1)

> §17.1 「9종 섹션 컴포넌트 + 삽입 블록 3종을 개발 단계에서 375 / 768 / 1280px에 대해 **1회 검증하고 결과를 문서화한다**」의 이행 문서.

서버리스 환경에서 헤드리스 브라우저 검사는 비현실적이므로, spec은 매 실행 검사 대신 **개발 단계 1회 검증 + 문서화**로 보증 방식을 바꿨다. 이 파일이 그 기록이다.

## 검증 방법

```bash
npm run dev
# 로그인 후
open http://localhost:3000/admin/preview
```

`app/admin/preview/page.tsx` — **개발 전용** 하네스. 프로덕션에서는 404이며 §14.1 라우트 표에 없다.

- 375 / 768 / 1280px **실제 폭 iframe 3개**를 나란히 띄운다. 브레이크포인트는 뷰포트 기준이라 고정 폭 `div`로는 재현되지 않는다.
- 테마 7종을 전환한다.
- 고정 데이터는 `components/page/fixture.ts`. **경계값으로 골랐다** — 검증은 평균이 아니라 경계에서 깨진다.

| 고정 데이터가 담은 최악 조건 | 노리는 실패 |
|---|---|
| `hero.headline` 정확히 40자 · `subcopy` 80자 · 일차 서술 200자 (§17.1 상한) | 상한값에서 줄바꿈·잘림 |
| `추후 추가 예정` · `해당 없음` (§6.1) | 표기가 사라지거나 `0`으로 바뀜 |
| 공백 없는 긴 URL (`상점정보`) | 줄바꿈 실패 → 본문 가로 스크롤 |
| 항공 5열 표 | 375px에서 페이지 전체가 가로로 밀림 |
| 이미지 0장 | 이미지 없는 섹션이 깨짐 |
| `visible: false` 블록 · 참조 끊긴 `image` 블록 | 숨긴 것이 보이거나 500 |

## 컴포넌트별 적용 규칙

`components/page/` — 전 컴포넌트가 `server-only`를 import하지 않는다. 공개 페이지(서버)와 편집기 미리보기(클라이언트)가 **같은 컴포넌트를 공유**해야 하기 때문이다.

| # | 컴포넌트 | 375 | 768 / 1280 | 적용한 규칙 |
|---:|---|---|---|---|
| 1 | `hero` | `aspect-[4/3]` | `md:aspect-[21/9]` | 전면 이미지 + 스크림. 미업로드 시 **테마 그라디언트 폴백**(§9.3). 흰 글자는 스크림 위라 12:1 이상 |
| 2 | `summary` | 1열 | `sm:` 2열 | `dl` 격자, `break-words` |
| 3 | `itinerary` | 이미지 아래로 | `md:` 본문 + 240px 이미지 2열 | 슬롯이 비면 **이미지 열만** 사라지고 일차는 남는다 |
| 4 | `accommodation` | 1열 + 갤러리 2열 | `sm:` 2열 | 슬롯 상한 3장(§7.3) |
| 5 | `flight` | **자체 가로 스크롤** | 전체 표시 | `overflow-x-auto` + `min-w-[34rem]`. 페이지 본문은 밀리지 않는다 |
| 6 | `meal` | 1열 | 동일 | `whitespace-pre-line` |
| 7 | `price` | 카드 1열 | `sm:` 2열 | **총액 계산 없음**(§13.3) |
| 8 | `shop` | 1열 + 갤러리 2열 | `sm:` 2열 | 슬롯 상한 2장 |
| 9 | `apply` | 요약 1열 | `sm:` 2열 | 폼 5필드는 `data`가 아니라 **고정 컴포넌트**가 그린다(§13.1). `form` prop으로 주입 |
| 10 | `free_text` 블록 | 1열 | 동일 | 500자 상한은 **저장 시** 강제(§17.1) |
| 11 | `image` 블록 | `aspect-[16/9]` | 동일 | `product_images.id` 직접 참조. 참조가 끊기면 조용히 생략 |
| 12 | `notice` 블록 | 1열 | 동일 | 300자 상한은 저장 시 강제 |

### 공통

| 계약 | 구현 |
|---|---|
| 고정 종횡비 + `object-fit: cover` + `max-width: 100%` | `components/page/media.tsx`의 `RATIO` 3종 + `fill` + `object-cover` |
| 가로 스크롤은 자체 컨테이너 안에서만 | 항공 표만 `overflow-x-auto`. 루트에 `overflow-x-hidden` |
| `hero`는 `priority`, 나머지는 lazy | `next/image` 기본이 lazy |
| 대체 텍스트 필수 | 업로드 시 자동 채움까지 마쳐 `alt`가 비지 않는다(§7.3) |

### 대비 4.5:1 (§17.2)

**본문 텍스트에 투명도를 쓰지 않는다.** Tailwind의 `/60`은 `color-mix`로 배경을 섞어 실효 대비를 떨어뜨린다 — 어두운 글자를 밝은 배경 위에서 65%로 낮추면 **2.5:1**까지 내려가 기준 미달이다. 위계는 크기·굵기·대문자·이탤릭으로만 만든다. 투명도는 테두리·배경에만 쓴다.

| 조합 | 대비 |
|---|---|
| 본문 `--t-text` on `--t-surface` (7테마) | 12:1 이상 |
| `block-accent` 흰 글자 on `--t-primary` (6색) | 4.8:1 이상 |
| `pill-badge` `--t-text` on `--t-secondary` | 9:1 이상 |
| 히어로 흰 글자 on 스크림 | 12:1 이상 |

미입력·미운영 표기는 **색을 흐리지 않고 이탤릭으로** 구분한다.

### 미완 — 3뷰포트 육안 확인

**아직 하지 않았다.** 위 항목은 마크업 대조이지 렌더링 결과가 아니다. 375/768/1280에서 실제로 밀리거나 겹치는지는 `/admin/preview`를 열어 눈으로 봐야 한다.

- [ ] 375 — 가로 스크롤 0, 항공 표만 자체 스크롤, 히어로 40자 헤드라인 2~3줄 수용
- [ ] 768 — 2열 전환 지점에서 겹침 없음
- [ ] 1280 — 본문 폭 `max-w-3xl` 고정, 히어로만 전면
- [ ] 테마 7종 전환 시 대비 이상 없음

### 이 문서에서 다루지 않은 것

- **실제 이미지가 붙은 상태의 검증.** 고정 데이터는 이미지 0장이다. Supabase Storage URL이 `next/image`를 통과하는지는 `/p/{slug}`에 실제 업로드본이 올라간 뒤 확인한다(`next.config.ts`의 `remotePatterns`가 `SUPABASE_URL` 호스트로 좁혀져 있다).
- **편집기 미리보기의 뷰포트 전환**(§10.1). 편집기 구현 시 이 하네스와 같은 iframe 방식을 쓴다.
