> **2.8**: 「섹션 9개·순서」를 버렸다. **어휘 준수 · `source` 커버리지 · hero/apply · order 1..n 연속 · 타입별 길이**로 검사한다(§9.5·명령서 ⑤). 커버리지는 확정 데이터의 모든 사실정보 경로가 페이지 어느 블록에든 있으면 통과다(`해당 없음` 제외).


## 단일 기능

`page_content`의 **구조**를 검사한다. 사실정보의 값은 2차 검증(`fact-check`), 소개서와의 일치는 3차(`consistency-check`)의 일이다.

## 배선

`manifest.json`이 유일한 출처다. 요약: `web-builder-agent` · `page` 체인 4번 · AI 0회 ·
`impl: pipeline/page#checkPage`.

## 입력

| 항목 | 형식 | 설명 |
|---|---|---|
| `page_content` | object | 조립이 끝난 페이지 |
| `이미지슬롯` | Set of string | 실제로 채워진 이미지 슬롯 키 |

## 출력

| 항목 | 형식 | 설명 |
|---|---|---|
| `위반사유` | array of string | 사람이 읽을 사유 문장. **0건이면 통과** |

## 검사

| # | 검사 | 근거 |
|---:|---|---|
| 1 | 섹션이 정확히 9개이고 `id`·순서가 `PAGE_SECTION_IDS`와 일치 | §9.2 |
| 2 | 사실정보 필드에 `source` 누락 0건 | §9.3 |
| 3 | 이미지 슬롯이 선언된 자리에만 있고 재배치되지 않았다 | §9.2 |
| 4 | 생성 시점 길이 계약 **4종** 위반 0건 | §17.1 |

### 섹션 9개

히어로 · 요약 · 일정표 · 숙박 · 항공 · 식사 · 가격 · 제휴상점 · 신청.

### 길이 계약은 생성 시 4종이다

`free_text`(500자)·`notice`(300자)는 **편집기에서 사람이 끼워 넣는 블록**이라 생성 시점에 존재하지 않는다.
그 2종을 여기서 검사하도록 요구하면 실행 불가능한 규정이 된다. 6종은 편집 저장 시점의 계약이다(§17.1).

## 판정 규칙

- 사유를 모아서 반환한다. 첫 위반에서 멈추지 않는다.
- 이미지 슬롯이 비어 있는 것은 위반이 아니다. **재배치**가 위반이다.
- **재시도 여부를 판단하지 않는다**(R7).

## 금지 사항

- AI를 호출하지 않는다.
- `page_content`를 수정하지 않는다. 이미지 슬롯을 재배치하지 않는다.
- 사실정보의 값을 판정하지 않는다.
- 편집 시점 6종 계약을 생성 시점에 적용하지 않는다.
- HTML을 생성·검사하지 않는다. 렌더링은 고정 React 컴포넌트다(§9.1).

## 하네스 계약

`asserts`: 반환값은 문자열 배열이어야 한다(0건은 `[]`).
